# ⚖️ NahomiJustice v1.0

**Documenta tu caso legal de forma clara, sencilla y privada.**

> *"La mejor tecnología no es la más compleja, sino la que resuelve problemas reales con claridad y propósito"*

## ✨ Características

- 📝 Documenta tu caso paso a paso
- 📸 Adjunta fotos y documentos como evidencia
- ⚖️ Consulta leyes aplicables a tu situación
- 💾 Guarda tu caso como archivo JSON (100% privado, todo en tu equipo)
- 🖨️ Genera un reporte imprimible
- 🌙 Modo oscuro/claro incluido

## 🚀 Cómo usar

1. Abre `NahomiJustice.html` en tu navegador
2. Carga una base legal (los archivos `.json` incluidos)
3. Explora las situaciones legales en el panel izquierdo
4. Crea tu caso personalizado con el botón "Crear mi Caso"
5. Guarda, imprime o exporta tu documentación
